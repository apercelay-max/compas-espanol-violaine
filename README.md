# Compás — version Violaine

Application d'apprentissage de l'espagnol (français → espagnol), style Duolingo, en une seule page HTML autonome. Copie de Compás adaptée pour Violaine : **départ au niveau B1, objectif C2**.

- **Vocabulario** — flashcards SRS (B1 → C2), 340 mots rangés par situation, carte à volet 3D, direction français → español.
- **Gramática** — 20 leçons (5 par niveau : B1, B2, C1, C2) avec exercices QCM / à trous.
- **Modo coche** — mode mains libres (trois boutons, tout à la voix : phrases connues définitives, groupes de 15, cartes de grammaire B1→C2) pour réviser le vocabulaire sans regarder l'écran.

Ouvrez `index.html` dans un navigateur pour lancer l'app.
